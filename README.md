# hf-presenter-broll

给**已经剪好的中文真人口播视频**补充相关B-roll、真实资料和HyperFrames动效的Agent Skill。默认保留原声、语序、剪点和时长；自动初剪仅在明确要求时启用。

## 它怎么工作

1. 检查运行环境、原片和素材，说明缺失配置及其影响。
2. 理解整条口播及“这样”等指代，确认本次风格。
3. 逐段分别决定是否出镜、补什么画面、用什么素材以及发生什么变化。
4. 给出完整制作任务，经审查后制作。
5. 核对源音轨、实际素材入片、词锚与输出帧，再检查视觉解释效果。

支持真人配辅助画面、全屏内容、圆形/圆角矩形小窗和分屏。默认使用真实载体和操作展示，避免用通用文字卡片替代内容。

## 安装

下载本仓库ZIP并解压，将包含SKILL.md的整个目录命名为`hf-presenter-broll`，放入Agent的技能目录。不要多嵌套一层文件夹。

Codex：放入自定义CODEX_HOME下的skills目录；未自定义时放入用户目录的`.codex/skills/`。刷新或重开会话，调用`$hf-presenter-broll`。

```text
请使用 $hf-presenter-broll 处理我提供的已剪口播视频。
保持原声、语序、剪点、比例和时长。
先检查环境与素材，理解全文，给我本次的风格选择。
再规划B-roll、人物显隐和动效，展示完整制作任务，等我审查后制作。
视频路径：[填写你的本地MP4路径]
脚本/字幕/截图/录屏：[填写已有材料]
```

## 需要什么

完整制作需要能读写本地文件、执行终端、查看媒体的Agent，以及Node.js 22+、npm、FFmpeg、HyperFrames及对应技术Skill、浏览器。需要转写或生成素材时，还需本次实际使用的服务或工具。Skill不含这些运行时、模型、账号或生成额度。

缺配置时先说明并询问是否协助配置；已验证齐全才继续。安装本Skill不等于安装全部依赖。

其他平台按实际能力使用：能运行工具并导出MP4的执行完整流程；能规划和写工程但不能渲染的交接工程；普通对话只做规划。本机短样例验证不代表WorkBuddy、CodeBuddy或豆包都已完整跑通。
