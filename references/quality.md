# 验收和交付

## 渲染前

检查所有关键锚使用真实音频，JSON引用有效；场景覆盖完整时长，不漏后半段。所有核心Scene有连续语义演进，高冲击点有镜头响应/hold_reason，真实素材有阅读动作。技术门使用当前CLI check，不能只lint。

## 渲染后

对真实MP4运行ffprobe查看音/视频轨、FPS、分辨率、时长；完整解码：`ffmpeg -v error -i <成片.mp4> -f null -`。检查音频不是空/静音，听开头、中段、结尾与全部剪点/高冲击段；检测到静音不是自动失败，结合原片判断。比较原片与成片时长，默认容差一输出帧，超出须解释且获准。

核对原声语序、剪点、字幕和操作证据保留；原片结尾没截断，也没多出黑尾。至少完整观看成片一次；工具无法播放时记录无法验证项，不能声称完整审片通过。

所有impact_score≥4，以及关键数字/专名/结论，在真正MP4提取HIT−2、HIT、HIT+4、SETTLE四帧；边界超界时使用最近合法帧并注明。报告逐项记录锚点、预期/实际帧、4张相对路径、可见状态、提前揭晓情况、人物/字幕/ROI安全、结论。CLI snapshot只证明预览，不代替MP4帧证据。

检查两个观看尺寸：原始分辨率与手机阅读尺寸。完整头部、字幕、关键数字可读；没有细小角落贴纸、泛滥logo、无关图、乱码UI、未注明示意、成绩/积分/金额混用。检查转场中间帧、人物遮罩边缘、后半段，不能只审第一屏。

Canvas或视频底片内部的文字不一定被HTML布局/对比度检查覆盖；技术检查通过后，仍须从实际输出帧检查其字体大小、对比度与阅读时间，不能用外层容器检查冒充内部内容验收。

`DIRECTORIAL_QUALITY_REVIEW.md`结构：

- Video: renders/final.mp4（实际文件名）
- 实际媒体参数与完整解码结果
- 原片保留与音轨核对
- 逐Anchor四帧证据表
- 连续演进/人物/素材真实性/阅读与ROI安全检查
- 未通过项与修复帧号
- 结论：PASS / FIX_REQUIRED / BLOCKED

任一硬失败不能PASS；画面提前演完、只有入场、缺词锚、裁断头发、掩盖关键操作、未授权删改原片、无音轨、无逐锚点证据均阻塞最终交付。修复后检查实际重渲染文件。

## 交付

### 口播展示质量

按连续段落实际播放检查：画面是否回应整条口播主题、指代是否清楚、主体是否足够大、状态变化是否来得及读、人物与内容交接是否自然。不要把所有名词都触发一次动画；词锚控制关键命中，句子和动作过程控制连续展示。字幕、原声和画面节拍需共同审查。

对有争议的B-roll做相同口播下的有/无画面对照，分别检查理解、证据、操作、情绪或节奏用途。评审者先看播放文件再看制作理由，记录实际观察、失败时间点及修改方案。删除后理解不变并非必删，情绪和节奏作用可成立；一句话复述旁白也不自动失败。由制作者自写的“有效”不能证明独立反馈。

写代码后的资产以命名HTML对象/实现文件、文件摘要、使用帧段登记；渲染后在 `BROLL_DELIVERY_EVIDENCE.json` 保存真实MP4摘要与每项B-roll的实际输出帧，运行 `validate-delivery-evidence.mjs --dir <项目>`。格式见脚本和 [产物字段](artifacts.md)。它只给EVIDENCE_LINKS_PASS，帧与资产是否真的相符仍要看；禁止把该结果改写成视觉PASS。未完整观看保持UNVERIFIED。原生计划、已实现、渲染证据、导演认可分别记录。

交付最终MP4、可编辑HF工程、相对路径素材/字体、锁文件、原片映射、词锚与导演产物、来源清单及导演报告。大原片无法随工程分发时列准确输入依赖与重新链接方法，不宣称工程完全离线自含。区分“规划完成 / 预览 / 渲染完成待审 / 正式通过”。

## 画面方向验收

对照已审查任务及REVIEW_EVIDENCE.json的card_policy检查实际MP4。NO_GENERIC_CARDS时，通用标题框、便签和标签盒不得成为主要解释。真实窗口、文件边界不因矩形外观被误禁。若移除文字标签后只剩空盒、重复真人截图，而看不出具体对象或过程变化，记FIX_REQUIRED。效果展示的多个指代必须有不同且可辨认的画面；逐段写出真实载体、状态变化及帧证据。Shotcraft覆盖率或技术通过不替代此项。

## 人物显隐验收

对照导演表检查实际MP4：CONTENT_ONLY段无残留人像、原声连续且不重复；圆形/矩形小窗只出现在有价值的段落，完整头部/必要手势不被裁断；不压字幕或操作ROI。全片真人可见且有内容展示段时，复核是否只是惯性保留人物。允许有理由的纯真人片，不靠固定隐藏比例判定质量。
