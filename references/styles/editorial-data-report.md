# 编辑型数据简报 / 发布会数据报告

- ID：`editorial-data-report`
- 适用：AI发布解读、数据观点、榜单、能力与成本对比。
- 视觉：编辑部报告版式，深浅底可切换；标题、数字、证据图和注释形成清楚层级。
- 载体：真实榜单、表格、模型卡、价格页、图表和来源摘录；数值必须带单位、时间和口径。
- 动作：先提出判断，再让证据写入；数字计数、排名重排、对比展开、来源ROI推近，结论最后锁定。
- 排版：中文展示可用思源宋体重字，正文用 IBM Plex Sans SC，数字与短标签用 IBM Plex Mono。
- 禁止：只用抽象仪表盘代替真实数据、同屏堆满指标、在词锚前提前揭示结论。
