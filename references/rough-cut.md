# 可选初剪：仅在明确要求时启用

默认建议使用已经人工剪好的口播。本分支不等于“一键可靠去废话”。

1. 先完整转写和检测音画，找口误、明确重录、过长空白的候选；保留语气、呼吸、强调和关键事实。
2. 输出EDL候选：源入/出时间、原话、保留/删除、理由、置信度，展示删前删后文本。不因语速慢、停顿或重复就自动删除。
3. 用户已经明确指定剪辑规则且授权时按范围执行；涉及含义改变或无法判断的重录版本须在EDL审查中解决。不要擅自变速或重配音。
4. 从原片派生新文件，原片不覆盖；剪点检查口型、吞字、呼吸断裂、爆音、字幕残留和画面跳切。
5. 输出 `EDIT_DECISION_LIST.json` 和 `SOURCE_TO_OUTPUT_MAP.json`。原片时间、初剪输出时间分别保存，重新生成输出词锚和字幕；禁止沿用旧秒数。
6. 以审核过的初剪文件作为增强入口，回到主流程。初剪完成不等于B-roll已完成。
