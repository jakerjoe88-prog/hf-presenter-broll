# 公开版构图说明

内部静态肖像参考图不公开分发。本文件是可执行构图规则，不是新用户的风格确认，也不是动画或成片验收证明。

- 真人主讲：保持原片构图与头部完整，把有用的真实资料放在原片留白处。主体要在目标观看尺寸可读，不用重复的小人像和标签填空。
- 内容主导：实际操作或结果需要充分空间时，隐藏或缩小人物；保持原声连续，主体充分展开。
- 小窗：人物提供额外信息才保留。矩形使用适度圆角；圆窗和矩形可使用细边框与轻阴影。先按头肩位置裁切，再定位，不能只按原片几何中心裁切。
- 每个画面有具体对象、明确来源、可见状态变化和一个阅读焦点。丰富度来自内容与过程，不是元素数量。
- 实际MP4检查真人、字幕、关键操作ROI、词锚同步、手机阅读尺寸和段落交接。
